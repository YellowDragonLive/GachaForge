# 运维：清理条目里的超重权重

词卡从外面导入时常自带 SD1.5 时代的手写权重：`(long petticoat:1.2)`、`(a, b:1.3)`、
`anal beads:1.2`、`((gothic lolita, Idol costume):1.3)`。这些在抽卡里是污染 ——
一个条目只是「一个概念」，强调程度该由抽卡时的人决定，不该由词卡写死 1.2/1.5。

固定入口：

```bat
python scripts/clean_weights.py                  :: 只看清单与样例（默认 dry-run，绝不写库）
python scripts/clean_weights.py --yes            :: 执行
python scripts/clean_weights.py --yes --keep-brackets    :: 只删权重，保留 ()
python scripts/clean_weights.py --min 1.1 --max 3        :: 自定义权重区间
python scripts/clean_weights.py --no-label       :: 只清 tags，不动 label
python scripts/clean_weights.py --self-test      :: 只跑内置用例，确认规则没被改坏
```

导入了一批新词卡之后就跑一次 dry-run；命中数不为 0 时先看样例前几条，再 `--yes`。

## 规则（实现见 `backend/app/core/weights.py`）

| 输入 | 输出 | 说明 |
| --- | --- | --- |
| `(standing:1.2)` | `standing` | 连括号一起删：留着 `(standing)` 仍是 1.1 倍强调 = 没清干净 |
| `(bottomless, lying:2)` | `bottomless, lying` | 整组权重 |
| `((gothic lolita, Idol costume):1.3)` | `(gothic lolita, Idol costume)` | 双括号：删外层权重，内层是原本的强调，保留 |
| `(a (b:1.2):1.3)` | `a b` | 嵌套由内向外剥 |
| `anal beads:1.2` | `anal beads` | 裸权重（整段以 `:数字` 结尾） |
| `ribbons:1.2)` （丢了开括号的坏数据） | `ribbons` | 孤立权重兜底，顺带删多余的后括号 |
| `<lora:name:0.7>` / `<lyco:...>` | 原样 | 尖括号整段跳过，里面是 LoRA 权重 |
| `reverse:1999` / `(重返未來:1999)` | 原样 | 权重区间默认 1.1~5.0，年份冒号不会被误吃 |
| `(bloom:0.5)` | 原样 | 降权不在清理范围（只清超重） |
| `((full body))` | 原样 | 没有 `:数字` 的括号强调不算权重，脚本不猜 |

## 安全口径

- 默认 dry-run，必须 `--yes` 才写；写库前用 SQLite backup API 备份到
  `data/backups/gacha-weight-<时间戳>.db`（WAL 未落盘也能拿到一致快照）。
- 单事务提交，失败整体回滚；`content_hash` 同步重算（它是 label+tags 的导入去重指纹）。
- 幂等：清完再跑一遍命中数为 0；脚本结尾会自己复查一遍并打印「复查残留」。
- 没有超重权重的条目**一个字都不改**：不顺手把 `1girl,1boy` 补成 `1girl, 1boy`，
  否则 3 万条全都变成「已修改」，diff 没法看。
- 括号不配对的（`(a:1.2` 缺后括号）只清能清的，脚本会在 dry-run 里点名列出，
  剩下的按需人工处理 —— 脚本不猜括号往哪儿配。

## 影响面

- 只改 `pool_items.label` / `pool_items.tags`（条目字典）。
- 不动：`payload_json`、`pools.template`、配方 `recipes`、`gen_profiles`、
  历史抽卡 `draw_slots/draw_slot_tags`、已出图记录。
- 概念索引（`concepts` / `concept_images`）的 key 来自 tag 文本，清理后旧 key 可能残留；
  需要时重建：`python scripts/rebuild_concepts.py`。
