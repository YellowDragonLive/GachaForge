## 0. 一句话结论

现有代码不是"一个应用"，而是**两套服务 + 45 个一次性脚本 + 5 份互相不同步的数据副本**。
重构的核心不是换语言，而是三件事：**数据收拢到 SQLite 单一事实源**、**ComfyUI 从"黑盒子进程"改成"直连 API + 异步任务"**、**前端收敛成一套零框架原生页面**。

### 0.1 决策记录（用户 2026-11-15 拍板）

| # | 决策 | 对方案的调整 |
|---|---|---|
| 1 | **前端越简单越好，不用框架** | 取消 Vue3 / TypeScript / Vite / Pinia / 构建链。改为**原生 HTML + CSS + ES Modules 单页多视图**，后端 `StaticFiles` 直接托管；零 npm、零编译、零打包。OpenAPI 仍保留，但只作接口文档，不生成 TS 客户端 |

| 3 | **画师图鉴并入新画廊** | `noobai_data.json` 的 artists 列表导入为「画师」卡池；原 `server.js` / `index.html` 图鉴能力并入新「画廊」视图。实测 `artist_style_test_20260526/`、`yoga_style_guide_20260527/` 两个历史图片目录当前**不存在**，故画廊提供「扫描外部图片目录注册」入口，目录出现后即可挂载，不阻塞上线 |
| 4 | **词卡库来源**：`https://github.com/sdbds/stable-diffusion-webui-wildcards.git` | 已实测克隆到 `vendor/stable-diffusion-webui-wildcards/`，词卡根 = `vendor/stable-diffusion-webui-wildcards/wildcards`，**564 个 .txt**。路径写进 `.env`，启动时校验 |
| 5 | **一条 `start.bat` 起全套** | 后端 Uvicorn 同时托管前端静态页，`start.bat` 负责：校验 Python → 装依赖（首次）→ 建库/迁移 → 导入旧数据（首次）→ 启动服务 → 打开浏览器。`vendor/`、`data/` 不入库 |

## 2. 目标与边界

**产品定义**：从若干卡池按配方随机组合 → 生成一组 prompt → 一键批量送本地 ComfyUI 出图 → 图片连同全部可复现信息落库 → 在画廊筛选、对比、复现、导出。

**四条原则**
1. **单一事实源**：卡池/条目/配方/参数/结果只在 SQLite，文件仅作导入来源与导出产物。
2. **ComfyUI 一等公民**：后端持有 workflow 模板与 `prompt_id`，进度可观测、任务可取消。
3. **可复现**：`seed + 配方快照 + 参数快照 + workflow 版本 + 图片 sha256`。
4. **本地单机零部署**：一条 `start.bat`，无 Docker / Redis / npm / 云账号，绑定 `127.0.0.1`。

**本轮不做**：多用户/公网部署、云端生图、模型训练、在线图片编辑、移动端适配。

## 3. 技术选型（六项）

| 项 | 选择 | 理由 |
|---|---|---|
| 后端 | **Python 3.13 + FastAPI + Uvicorn + Pydantic v2** | 复用现有 Python 抽卡算法；自带 OpenAPI 与边界校验 |
| 前端 | **原生 HTML + CSS + ES Modules**（零框架、零构建） | 用户明确要求最简；后端静态托管，改完刷新即生效，无工具链负担 |
| 数据库 | **SQLite（WAL）+ SQLAlchemy 2.0 + Alembic** | <1MB 数据、单文件可备份；迁移可回滚，Repository 隔离后未来可换 PG |
| 接口 | **REST + OpenAPI（文档用）** | 本地工具无需 GraphQL/gRPC；前端用一个 `api.js` 统一封装 |
| 实时 | **SSE**（`GET /api/jobs/stream`）+ 任务表轮询兜底 | 单向进度推送，浏览器原生断线重连 |
| 认证 | **默认免登录，仅监听 127.0.0.1**；预留 `GACHA_TOKEN` | 单人本地工具上 JWT/RBAC 属过度设计 |

> 简化是**有意的**：把复杂度花在"任务可靠性 + 可复现"，而不是认证与构建链。接口层仍保留标准中间件顺序与依赖注入。

## 6. ComfyUI 集成

**现在**：`HTTP → subprocess.run(skill/main.py) → 正则抓 [SUCCESS] → 扫目录猜图片`。
**改成**：自有 workflow 模板 + ComfyUI HTTP / WebSocket API 直连。

```
backend/workflows/sdxl_minimal.json  （全部为 ComfyUI 内置节点）
  CheckpointLoaderSimple → LoraLoader×N（可选）→ CLIPTextEncode ×2
  → EmptyLatentImage → KSampler → VAEDecode → SaveImage
参数化：{{PROMPT}} {{NEGATIVE}} {{SEED}} {{CKPT}} {{WIDTH}} {{HEIGHT}}
        {{STEPS}} {{CFG}} {{SAMPLER}} {{SCHEDULER}} {{LORA_CHAIN}} {{PREFIX}}
```

`ComfyClient` 职责：

| 能力 | 接口 |
|---|---|
| 健康检查 | `GET /system_stats` → `/ready` 与前端状态灯 |
| 动态枚举 | `GET /object_info/CheckpointLoaderSimple`、`/LoraLoader`、`/KSampler` → 模型/LoRA/采样器下拉 |
| 提交 | `POST /prompt {prompt, client_id}` → `prompt_id` 落 `generation_jobs` |
| 进度 | `WS /ws?clientId=` 收 `progress / executing / executed / execution_error` → SSE 转发 |
| 取图 | `GET /history/{id}` → 输出节点 → `GET /view?filename=` 下载字节流落 `data/outputs/` |
| 取消 | `POST /interrupt` → 任务置 `cancelled` |
| 失败 | 重试 ≤3 次（指数退避），超限进死信；重启后恢复 `queued/submitted` |
| **mock 模式** | `GACHA_COMFY_MOCK=1` 时不连 ComfyUI，用本地 Pillow 生成占位图跑通全链路，供离线冒烟与前端联调 |

**收益**：进度可见、可取消、可重试、错误真实、图片与 `prompt_id` 强关联。旧 `gacha_to_sdxl.py` 冻结，不保留双链路。
