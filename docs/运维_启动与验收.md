# 运维手册 · 启动与验收

> **唯一口径**：本文件是启动、验收、排障的唯一依据。不要现场拼命令。
> 适用：`X:/image` 抽卡工作台 v1.0（FastAPI + SQLite + 原生前端）。

---

## 1. 启动（唯一入口）

双击项目根目录的 **`start.bat`**，或在终端执行：

```
X:\image> start.bat
```

它会自动完成：**生成 .env（首次）→ 检查/安装依赖（首次）→ 检测 ComfyUI → 建库/迁移 → 导入旧数据（仅库空时）→ 启动服务 → 打开浏览器**。

实际逻辑在 `scripts/start.bat`，服务由 `scripts/run_server.py` 拉起；地址与端口统一读 `.env`，默认 `http://127.0.0.1:8765/`。
按 `Ctrl+C` 停止服务。

### ComfyUI 在线检测

`start.bat` 会探测 `.env` 里的 `GACHA_COMFY_URL`：

| 情况 | 行为 |
|---|---|
| ComfyUI 在线 | 真实出图模式 |
| ComfyUI 离线 | **自动切到 mock 模式**（设 `GACHA_COMFY_MOCK=1`），生图返回占位图，抽卡/任务/画廊全链路照常可用 |

想强制固定模式，直接改 `.env` 的 `GACHA_COMFY_MOCK`；注意 `start.bat` 设置的环境变量优先级高于 `.env`，手动命令行启动时以环境变量为准。

> 旧的 `start.bat`（画师图鉴 3000 端口）和 `gacha_start.bat`（旧抽卡器 8765 端口）已分别改名为
> `start_legacy_gallery.bat` / `start_legacy_gacha.bat`，内容一字未改。**不要同时启动旧抽卡器和新服务**，两者默认都占 8765。

## 2. 固定命令表

| 想做什么 | 固定命令 |
|---|---|
| 启动全套 | `start.bat` |
| 冒烟验收 | `python scripts/smoke_test.py` |
| 建库 / 升级表结构 | `python scripts/init_db.py` |
| 迁移预览 | `python scripts/migrate_legacy.py --dry-run` |
| 重新导入旧数据 | `python scripts/migrate_legacy.py` |

| 备份数据库 | `python scripts/backup_db.py` |
| 查看备份 | `python scripts/backup_db.py --list` |
| 恢复数据库 | `python scripts/backup_db.py --restore <文件名>` |
| 查看接口文档 | 浏览器打开 `/docs`（FastAPI 自带 OpenAPI） |

冒烟脚本默认强制 mock，**不需要 ComfyUI 在线**，覆盖 27 项检查（算法一致性、复现、幂等、任务状态机、图片、静态页、错误结构）。

## 3. 验收清单

### 自动（每次改动后跑）

```
python scripts/smoke_test.py
```

必须输出 `== 汇总: 27/27 通过 ==`。任何 FAIL 都不要交付。

### 手工（首次上线 / 换机器后）

1. 双击 `start.bat`，浏览器自动打开，顶部状态灯显示「ComfyUI 在线」或「mock 模式（占位图）」。
2. **抽卡台**：选「角色 × 风格 × 背景」，连抽 3、种子 42 → 得到 3 张卡片；再抽一次种子 42，prompt 必须逐字相同。
3. **任务队列**：点「本批全部生图」→ 页面自动跳到任务队列，进度条从 0 走到 100，状态 `succeeded`；点「取消」/「重新生成」各验证一次。
4. **画廊**：能看到生成图缩略图，点开灯箱可看原图，收藏/评分可保存，「同参重跑」能再产生一个任务。
5. **卡池管理**：568 池可见；搜索、启停、条目预览可用；导入与批次回滚可用。
6. **配方编辑器**：新建/编辑/预览/删除均生效。
7. **双标签页**：两个标签都打开任务队列，提交一次生图，两边进度应同步（SSE）。
8. **设置**：能看到配置与 ComfyUI 模型枚举；保存参数预设后，新抽卡会话使用新参数。

### 真实出图验收（需本机 ComfyUI）

1. 启动 ComfyUI（`run_nvidia_gpu.bat`），确认 `http://127.0.0.1:8188/system_stats` 可访问。
2. 把 `.env` 的 `GACHA_COMFY_MOCK` 改为 `0`，重新双击 `start.bat`。
3. 进「设置」→ 从 `/object_info` 拉到的 checkpoint 下拉里选一个真实权重并保存预设。
4. 抽 1 张 → 生图 → 任务 `succeeded` → 画廊出现真实图片。
5. 若失败，看任务队列里的 `error_message` 与 `/api/logs`，常见原因见 §5。

后端用的 `backend/workflows/sdxl_minimal.json` **只用 ComfyUI 内置节点**
（CheckpointLoaderSimple / LoraLoader / CLIPTextEncode / EmptyLatentImage / KSampler / VAEDecode / SaveImage），
不依赖任何自定义节点插件；旧 skill 的 `resources/workflow.json` 未被复用。

## 4. 配置

复制 `.env.example` 为 `.env` 后修改（`start.bat` 首次会自动复制）。

| 变量 | 默认 | 说明 |
|---|---|---|
| `GACHA_HOST` / `GACHA_PORT` | `127.0.0.1` / `8765` | 只监听本机；改端口只需改 `.env`，`run_server.py` 会自动跟随 |
| `GACHA_COMFY_URL` | `http://127.0.0.1:8188` | ComfyUI 地址 |
| `GACHA_COMFY_MOCK` | `0` | `1` = 占位图模式 |
| `GACHA_COMFY_TIMEOUT` | `900` | 单任务等待上限（秒） |
| `GACHA_DB_PATH` | `data/gacha.db` | SQLite 文件 |
| `GACHA_OUTPUTS_DIR` / `GACHA_THUMBS_DIR` | `data/outputs` / `data/thumbs` | 图片与缩略图 |
| `GACHA_WILDCARDS_DIR` | `vendor/.../wildcards` | 词卡库根目录 |
| `GACHA_WORKFLOW_DIR` | `backend/workflows` | workflow 模板目录 |
| `GACHA_TOKEN` | 空 | 设置后 `/api/*` 需带 `X-Gacha-Token` 头；在「设置」页填入令牌后会存到本机浏览器并自动随请求带上 |

配置在启动时集中校验：workflow 目录、前端目录、ComfyUI 地址不合法会**快速失败**并打印原因，不会带病启动。

## 5. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 打开页面显示「无法连接服务」 | `start.bat` 窗口被关了；重新双击，或看窗口里的错误 |
| 提交生图提示「ComfyUI 未运行」 | 当前是真实模式但 ComfyUI 离线：启动 ComfyUI，或重启 `start.bat` 让它自动切 mock |
| 任务反复失败后进 `dead` | 看任务卡片里的错误信息 + `/api/logs`；多为 checkpoint 名不存在、节点类型不支持、显存不足 |
| 页面顶部显示「mock 模式（占位图）」 | 正常（离线保护），不是故障；要真实出图见 §3 |
| 抽卡报「没有可用的卡池」 | 数据库为空：跑 `python scripts/migrate_legacy.py` |
| 端口被占用 | 旧 `start_legacy_gacha.bat` 或别的程序占了 8765；改 `.env` 的 `GACHA_PORT` |
| 中文/路径异常 | 所有路径配置用相对项目根目录的写法；不要在工作区外放数据 |
| 本机设了 `HTTP_PROXY` 时接口偶发 404 | 代理会用 absolute-form 请求行转发（`GET http://host/path`）。后端已加归一化兼容；若仍异常，在环境变量里加 `NO_PROXY=127.0.0.1,localhost` |
| 图片不显示 | 检查 `data/outputs/` 是否被清理；`/api/images/{id}/file` 直接访问可定位是记录还是文件问题 |

## 6. 目录与旧文件

```
backend/    FastAPI 应用（app/core 纯算法 · app/services 业务 · app/api 控制器 · app/worker.py 任务）
frontend/   零框架静态页（index.html / styles.css / api.js / app.js），由后端托管
data/       gacha.db、outputs/、thumbs/、backups/（均不入库）
vendor/     克隆的词卡库（不入库）
scripts/    所有固定入口
docs/       本手册、数据迁移手册、重构方案
```

历史文件（旧 `gacha*.py`、`gacha.html`、`index.html`、`server.js`、`_run_*.py`、旧 JSON/CSV）
**全部保留原位、内容未改、不再被新系统使用**，已纳入 git 基线提交作为历史快照；
只有两个启动脚本为避免入口冲突而改名。根目录旧 `README.md` / `CHANGELOG.md` 描述的是另一套历史工具，以 `docs/` 为准。
